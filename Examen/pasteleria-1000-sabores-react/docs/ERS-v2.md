# ERS v2 – Pastelería 1000 Sabores

## Requerimientos funcionales (EV2)
- Migración a React con componentes reutilizables.
- Archivo de datos simulado con CRUD.
- Persistencia con localStorage.
- Diseño responsivo con Bootstrap.
- Vistas: Categorías, Ofertas, Carrito, Checkout, éxito/fallo, Admin.
- Pruebas unitarias con Jasmine y Karma.

## Herramientas
- React 18, React Router DOM, Bootstrap 5, Vite, Jasmine + Karma, Git/GitHub.

## Propuesta
- SPA con React Router.
- Datos en src/data/productos.js.
- CRUD y carrito en src/services/dataStore.js.
- Panel admin para gestionar productos.
