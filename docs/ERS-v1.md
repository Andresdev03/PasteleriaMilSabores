# ERS v1 – Pastelería 1000 Sabores

## 1. Requerimientos

### Funcionales (alcance evaluación 1)

- Sitio web con estructura HTML5 semántica.
- Navegación mediante hipervínculos entre páginas.
- Catálogo de productos con:
  - Listado de productos.
  - Filtro por categoría.
  - Búsqueda por nombre.
- Carrito de compras básico:
  - Agregar productos.
  - Modificar cantidades.
  - Eliminar productos.
  - Cálculo de subtotal, descuento y total.
- Formulario de registro:
  - Campos: nombre, email, edad, código promocional, contraseña y confirmación.
  - Validaciones con JavaScript.
  - Mensajes de error contextualizados.
- Descuentos:
  - 50 % para mayores de 50 años.
  - 10 % con código `FELICES50`.
- Video embebido.
- Footer informativo.

### No funcionales

- Diseño responsive básico.
- Uso de CSS externo.
- Código organizado y legible.
- Repositorio Git con commits descriptivos.

## 2. Herramientas

- HTML5, CSS3, JavaScript (ES6+).
- Git y GitHub.
- VS Code o IntelliJ IDEA.
- Navegador moderno.
- Live Server (opcional).

## 3. Propuesta del proyecto

- Frontend estático, sin backend ni base de datos en esta etapa.
- Carrito simulado con `localStorage`.
- Descuentos aplicados de forma básica según edad y código.
- Diseño alineado con la identidad visual del caso.
- Trabajo colaborativo mediante Git/GitHub.
